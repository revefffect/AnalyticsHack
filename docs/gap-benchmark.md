# Заполнение пропусков температуры · Сокол М1

Модель обучена на пригодных суточных измерениях 2024 года. В 2025 году маскировали последовательные блоки 1, 3 и 7 суток. Пара станций имеет 363 общих пригодных дня в 2024 году, от 90 до 91 на сезон. Метод переноса берёт измерение соседа на дату пропуска и добавляет сезонную медиану разности целевой и соседней станции по 2024 году.

| Цель | Маска | Перенос с соседней точки, MAE °C | Доля оценок | Профиль по месяцу, MAE °C |
|---|---:|---:|---:|---:|
| Кр1 из Кр2 | 1 день | 0,36 | 360/364 | 3,62 |
| Кр1 из Кр2 | 3 дня | 0,35 | 353/357 | 3,64 |
| Кр1 из Кр2 | 7 дней | 0,35 | 353/357 | 3,63 |
| Кр2 из Кр1 | 1 день | 0,36 | 360/360 | 3,72 |
| Кр2 из Кр1 | 3 дня | 0,35 | 351/351 | 3,75 |
| Кр2 из Кр1 | 7 дней | 0,35 | 336/336 | 3,80 |

Для однодневного разрыва линейная интерполяция даёт 1,20 °C у Кр1 и 1,17 °C у Кр2. В таблице каждая метрика приведена по датам, которые соответствующий метод смог оценить. JSON также содержит показатели по общим датам методов, смещения, MAE на крайних децилях и разбивку по сезонам.

Прогноз будущих суток оценивается отдельно. Для Кр1 сохранение последнего измерения даёт 1,94 °C MAE на горизонте один день и 4,20 °C на семь дней. Сезонный профиль на семь дней даёт 3,69 °C. Фиксация последнего значения соседа с поправкой даёт 1,96 °C на сутки и 4,30 °C на семь дней по 50 из 51 отсечек. Соседские наблюдения после выпуска исключены. Эти простые ориентиры задают порог для будущих SARIMA, ETS, Ridge и бустинга.

```sh
python tools/gap_benchmark.py data/raw/meteo_hack_dataset.zip
python tools/gap_benchmark.py data/raw/meteo_hack_dataset.zip --estimates > estimates.json
```

Вторая команда выгружает отдельный производный слой по реальным пропускам 2025 года для дат с пригодным соседним измерением и достаточной историей. Слой содержит станцию-донора, дату измерения, версию, размер калибровочной выборки и правило расчёта. При отсутствии соседа или менее 30 пар в сезоне модель воздерживается. Интервалы неопределённости не рассчитывались. Эксперимент проверен для двух соседних точек Сокол на одном временном разбиении. Перенос результатов на АМЕ-60 или внешние станции потребует собственной калибровки и проверки происхождения источников. [Опорные станции](nearby-stations.md).
