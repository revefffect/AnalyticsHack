# Что можно посчитать по данным урочища «Красное»

В апреле 2024 года у Кр1 достаточно наблюдений для среднемесячной температуры воздуха **+7,61 °C**. Для среднемесячного давления пригодны только **2 дня из 30**, и 28 неполных дней идут подряд. Сотрудник заповедника может включить температуру в отчёт и объяснить пустую ячейку давления. Оба вывода воспроизводятся на одном исходном файле.

## Состав и покрытие

| Станция | Период файлов | Годовых файлов | Строк наблюдений до фильтрации | Валидных месяцев на уровне станции |
|---|---|---:|---:|---:|
| АМЕ-60 | 1992–2021 | 27 | 805 561 | 254 из 324 месяцев в представленных годах |
| Сокол М1 Кр1, поляна | 2022–2025 | 4 | 36 544 | 32 из 48 |
| Сокол М1 Кр2, поле | 2022–2025 | 4 | 32 455 | 26 из 48 |
| **Итого** | | **35** | **874 560** | **312 из 420** |

Кроме наблюдений, в архиве есть отдельная таблица `coverage_by_month.csv` и README организаторов. Пересчёт по исходным срокам совпал с эталоном во всех **420 из 420** строк по обоим полям `valid_days` и `month_valid`. Пустые 2000–2002 годы АМЕ-60 отсутствуют в файлах и в знаменателе 324. В полном календарном интервале 1992–2021 насчитывается 360 месяцев. У первой и второй систем наблюдений разные точки и приборы. Общий график долгосрочного изменения через смену прибора в 2021/2022 годах методически недопустим.

## Контрольный пример для защиты

`data/sokol_m1/kr1_2024.csv` внутри архива содержит **17 247** наблюдений. За год **1 362** значения давления отмечены `pressure_hpa:range`, в том числе **1 272** из **1 389** апрельских записей. В тех же 1 389 строках флагов температуры воздуха нет.

| Срез Кр1 | Валидные дни апреля | Макс. серия неполных дней в апреле | Среднее за апрель | Валидные дни в 2024 | Валидные месяцы в 2024 |
|---|---:|---:|---|---:|---:|
| Станция | 28/30 | 2 | — | 363/366 | 12/12 |
| Температура воздуха | 28/30 | 2 | +7,61 °C | 363/366 | 12/12 |
| Атмосферное давление | 2/30 | 28 | Исключено по полноте | 334/366 | 11/12 |

**Как это проверить на экране.** Открыть Кр1 и апрель 2024, вывести температуру и число валидных дней. Переключиться на давление и открыть причину исключения. Верхняя граница диапазона давления — 1050 гПа, нижняя — 940 гПа. Строка с флагом `pressure_hpa:range` по-прежнему может содержать пригодные значения температуры, влажности и ветра. 117 оставшихся записей давления не гарантируют полноценный месяц.

## Январь АМЕ-60 и вес каждого года

За 1992–2021 годы среднемесячную температуру января можно посчитать для **13 из 30 календарных лет**. В расчёт вошли 1993, 1995, 1997, 1998, 2004, 2005, 2009, 2010, 2012, 2014, 2015, 2016 и 2021 годы. Эталон на уровне станции включает те же 13 январей. В README архива указана приблизительная оценка «около 14».

**Среднее за выбранный период равно −7,57 °C.** Для каждого года берём среднее по валидным суткам января, затем даём каждому валидному году равный вес. Это явное решение о весах. Температура января 2010 года равна −15,20 °C, отклонение от среднего за 1992–2021 годы составляет −7,63 °C. База включает сам 2010 год. Такой пример удобно проверять по таблице отдельных лет. Для подписи результата используем формулировку «среднее за выбранный период, 13 лет».

## Поляна и поле в 2025 году

Разность определена как температура на поляне Кр1 минус температура в поле Кр2. Для каждого дня рассчитываем среднее отдельно на каждой станции. В месяце берём только общие валидные даты, при условии, что месяц валиден на обеих станциях. Это сопоставление суточных средних. Для анализа суточного хода потребуется отдельно сопоставлять часы.

| Месяц 2025 | Общие валидные даты | Кр1 − Кр2, °C |
|---|---:|---:|
| Февраль | 28/28 | −0,56 |
| Май | 29/31 | +0,15 |
| Сентябрь | 30/30 | −0,57 |

За год нашлась **361 общая дата**. В мае на общих датах поляна была в среднем на 0,15 °C теплее, в сентябре — на 0,57 °C холоднее поля. Это наблюдаемые разности точек за конкретные периоды. Причинный вывод о влиянии типа местности требует отдельного исследования.

## Какие строки требуют внимания

| Измеренная особенность архива | Как показать или учитывать |
|---|---|
| 72 строки помечены `dup_conflict` и относятся к 36 срокам | Обе версии каждого конфликта исключаются целиком. Остаётся 874 488 строк для дальнейшей проверки по параметрам. |
| 5 022 записи АМЕ-60 вне стандартных четвертей часа, из них 4 909 за 2018 год, после исключения конфликтов | Для полноты использовать исходные уникальные отметки минут. Сдвиг или округление искажает временной ряд. |
| 12 416 отметок `soil_05:fault` и 87 отметок `soil_05:range` | Показывать причину исключения для датчика на глубине 5 см. Другие глубины проверяются отдельно. |
| 23 886 отметок `wind_dir:range` и 752 отметки `wind_dir:fault` | Для 1998 года колонка направления ветра отсутствует. За 2021 год направление недостоверно. В обоих случаях роза ветров недоступна, причины разные. |
| 1 983 отметки `pressure_hpa:range`, 11 `rh:range`, 88 `wind_gust:range`, 8 `soil_10:range`, 6 `soil_20:range` | Флаги учитываются отдельно по полям. Несколько меток могут относиться к одной исходной строке. |

## Как воспроизвести

Из корня репозитория с Python 3 и архивом по указанному пути выполнить:

```sh
python3 tools/audit_meteo.py data/raw/meteo_hack_dataset.zip
python3 -m unittest discover -s tests -v
```

Первая команда печатает JSON с контрольными числами, средними до округления, помесячным сравнением 2025 года и списком расхождений с эталоном. Все численные результаты выше рассчитаны из исходных строк. SHA-256 проверенного ZIP — `8c574c518617aea0f301997c62dfe75dc09b059abca1cdbd268645a3cd6cc33d`.

При расчёте сохраняются исходные дата и время. Для АМЕ-60 валидный день требует ≥72 уникальных сроков, для Сокола — ≥18 различных часов. Отбор дней выполняется отдельно для каждого параметра после применения его QC-флагов и удаления конфликтов. Внутри валидного дня среднее учитывает каждое пригодное измерение, включая несколько в один час. Для месячного среднего допускается ≤10 неполных календарных дней и самая длинная серия ≤4. Пропуски остаются пустыми. Скрипт проверяет общее покрытие всех станций и перечисленные контрольные показатели. Это независимая проверка чисел для приёмки приложения.
