# Развёртывание демонстрации в Yandex Cloud

Минимальное размещение использует одну обычную ВМ x86‑64 с Ubuntu 24.04 LTS. Стартовая оценка для планирования — 4 vCPU, 8 ГБ RAM и сетевой SSD 40 ГБ. Эти параметры учитывают два экземпляра Grafana и первичный импорт. Проверка нагрузки на выбранной облачной машине входит в приёмку. Командный проект включает прикладную часть в образе Python и демонстрационный архив.

## В консоли Yandex Cloud

1. Выберите каталог хакатона и подсеть в доступной зоне. Создайте ВМ с публичным IPv4, добавьте публичную часть своего SSH-ключа. В группе безопасности разрешите входящий TCP 22 со своего IP и 80/443 для посетителей. Исходящие соединения должны позволять разрешение DNS, загрузку образов, установку подписанного плагина Grafana и вызовы внешних API. [Создание ВМ](https://yandex.cloud/ru/docs/compute/operations/vm-create/create-linux-vm)
2. Для общей ссылки назначьте ВМ статический публичный IPv4 и DNS-имя, которое указывает на этот адрес. Для закрытой репетиции можно использовать SSH-туннель `ssh -L 8123:127.0.0.1:8123 <логин>@<IP>` и открыть http://localhost:8123.
3. Для этого варианта Compose создаёт PostgreSQL, обе Grafana, API и обработчик. Локальный приёмник webhook пригодится для репетиции. Публичные соединения принимает Caddy. Открывать 3000, 5432 и 8123 в группе безопасности не требуется.

## На ВМ

Установите Git, Python 3 и Docker Engine с плагином Docker Compose. Перенесите на ВМ проверенный коммит командного репозитория. Если ветка находится только на машине разработчика, вместо клонирования основной ветки передайте подготовленный Git bundle. Выполните из корня полученного проекта:

```sh
umask 077
python3 ops/init_env.py .env
chmod 600 .env
```

Для репетиции выполните `docker compose up -d --build`. Для публичного релиза добавьте в `.env` три строки, заменив имя домена своим:

```dotenv
WEATHER_DOMAIN=weather.example.org
PUBLIC_ORIGIN=https://weather.example.org
COOKIE_SECURE=1
```

Ссылка на атлас имеет вид `https://<имя>/portal?tab=atlas`. Для переадресации посетителей с IP на это же имя добавьте в `.env` строки `WEATHER_PUBLIC_IP=<статический IPv4>` и `WEATHER_CADDYFILE=Caddyfile.ip`. Caddy автоматически продлевает сертификаты имени и адреса. Том `caddy-data` хранит их между выпусками. [Сертификаты Let's Encrypt для IP](https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability)

```sh
docker compose -f compose.yaml -f compose.cloud.yaml config --quiet
docker compose -f compose.yaml -f compose.cloud.yaml up -d --build
docker compose ps
curl --fail https://weather.example.org/health
```

Ключ входа владельца — значение `RESEARCH_TOKEN`, ключ сотрудника — `BUSINESS_TOKEN`; передайте соответствующий ключ только участнику этой роли. Исследователь открывает «Импорт», выбирает пример организаторов, подтверждает маппинг и публикует набор в каталоге двух кабинетов. Сотрудник подключает опубликованную версию и сохраняет отчёт. Ключ интеграции `STREAM_TOKEN` служит для `POST /portal/stream/{dataset}`. Для настоящей доставки событий укажите контролируемый командой HTTPS-адрес `ALERT_WEBHOOK_URL`, затем пересоздайте worker. Пустое значение в Compose выбирает локальный приёмник.

## Где лежат данные и когда подключать сервисы

| Компонент | Демонстрационная поставка | Вариант дальнейшей эксплуатации |
|---|---|---|
| Версии, выдача прав, события, очередь доставки | PostgreSQL 18 в томе `postgres` | Закрытый Managed Service for PostgreSQL в сети ВМ. Перенесите данные, замените `DATABASE_URL` у API и worker в конфигурации Compose, уберите зависимость от локальной БД. Адрес, порт, CA и параметры TLS возьмите из раздела «Подключение» своего кластера. Одной замены `.env` в стандартном Compose недостаточно. [Подключение](https://yandex.cloud/ru/docs/managed-postgresql/operations/connect/index) |
| Неизменяемые исходники, месячные разделы | Том `observations`, имена объектов по SHA-256 | Закрытый бакет Object Storage. Задайте `WEATHER_BUCKET`, `S3_ENDPOINT=https://storage.yandexcloud.net`, `AWS_DEFAULT_REGION=ru-central1` и статический S3-ключ сервисного аккаунта, ограниченного этим бакетом. Выберите хранилище перед первым импортом либо перенесите уже созданные объекты по их хэшам. [Настройка boto3](https://yandex.cloud/ru/docs/storage/tools/boto) |
| Расчёт и визуализация | Один и тот же FastAPI готовит таблицу, CSV и данные для Grafana | Две Grafana изолируют рабочие пространства; отдельные серверные ключи источника ограничены разрешёнными версиями на стороне API. |
| Языковой помощник | Кабинеты, отчёт и воспроизведение потока работают самостоятельно | Контракт агента описан в документации выпуска. Доступ к AI Studio из предыдущего локального помощника подключается отдельно. Ресурсы GPU на ВМ для облачной модели не требуются. |

Перед защитой откройте сайт с другого устройства, проверьте сертификат, вход обеих ролей, импорт, CSV, отображение графика и доставку на свой получатель. Для восстановления нужны согласованные копии PostgreSQL и тома с объектами, файл секретов в защищённом месте и конфигурация развёртывания. Одна ВМ остаётся одной точкой отказа. Живую публикацию подтверждают адрес, проверенный снаружи, и коммит поставки.
