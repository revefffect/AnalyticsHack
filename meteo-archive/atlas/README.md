# Метеоархив · Атлас

Интерактивный экран «Набор Кр1 · апрель 2024», экспортированный из Claude Design. В коде страницы заданы демонстрационные значения температуры и давления. Для работы с загружаемыми наборами используйте [портал Метеоархив](../README.md).

Из корня AnalyticsHack запустите локальный сервер и откройте страницу Атласа.

```bash
python3 -m http.server 8078 --bind 127.0.0.1 --directory meteo-archive/atlas
```

[Открыть Атлас локально](http://127.0.0.1:8078/Main.dc.html)

`Main.dc.html` содержит экран и демонстрационные данные. `canvas.json` хранит размеры и настройки артборда. В `_runtime/` находятся файлы, необходимые для запуска экспорта. Шрифты загружаются с Google Fonts. [Лицензия React](./_runtime/LICENSE.react.txt)
