# Grafana и InfluxDB для метеостанций

Первое подключение показывает среднюю температуру воздуха Кр1 за 2024 год. Скрипт использует правила расчёта EDA. InfluxDB хранит готовые суточные точки, Grafana читает их и показывает график. Исходный ZIP остаётся источником наблюдений.

## Запуск на Mac

1. Открой Docker Desktop и дождись запуска. Из корня репозитория выполни команду в Терминале.

   ```bash
   docker compose -f integrations/grafana/compose.yaml up -d
   ```

2. Открой [InfluxDB](http://localhost:8086), создай локального пользователя и задай организацию `zapovednik` и bucket `meteo` с бессрочным хранением. В **Load Data → API Tokens** создай токен записи и отдельный токен чтения для bucket `meteo`.

3. В окружении проекта с Python 3.12+, pandas и NumPy выполни импорт из полного ZIP. Если окружения ещё нет, создай его командой `python3 -m venv .venv`, активируй `source .venv/bin/activate` и выполни `python -m pip install 'pandas>=2.2,<4'`. Подставьте путь к ZIP организаторов. Терминал попросит токен записи, ввод скрыт.

   ```bash
   python -m scripts.sync_influx_demo "$METEO_ARCHIVE"
   ```

   Можно добавить `--dry-run`, чтобы пересчитать значения и проверить число точек без подключения к контейнеру. Ожидается 363 суточных средних. Сутки без пригодного среднего отсутствуют в серии. Поле времени соответствует полуночи UTC для метки архивного календарного дня.

4. Открой [Grafana](http://localhost:3000). При первом запуске стандартный логин и пароль — `admin`, после входа задай свой пароль. В **Connections → Data sources → Add data source** выбери **InfluxDB** и задай настройки.

   | Поле | Значение |
   |---|---|
   | Query language | `Flux` |
   | URL | `http://influxdb:8086` |
   | Organization | `zapovednik` |
   | Default Bucket | `meteo` |
   | Token | Токен **чтения** для `meteo` |

   Нажми **Save & test**. Grafana обращается к `influxdb` по имени контейнера в общей сети Docker.

5. Создай панель **Time series**, выбери этот источник и вставь запрос. На дашборде установи часовой пояс **UTC**. Для полного апреля введи абсолютный диапазон с **1 апреля 2024, 00:00** до **1 мая 2024, 00:00**. Для оси Y выбери градусы Цельсия.

   ```flux
   from(bucket: "meteo")
     |> range(start: v.timeRangeStart, stop: v.timeRangeStop)
     |> filter(fn: (r) => r._measurement == "meteo_daily" and r._field == "mean_c" and r.station == "kr1")
   ```

Grafana и InfluxDB доступны с этого компьютера. Контейнеры можно выключить командой `docker compose -f integrations/grafana/compose.yaml stop`. Данные сохраняются в томах Docker. Повторный импорт тех же суточных точек использует те же станцию и даты.

## Когда появится доступ к станциям

Добавь загрузчик для API «Сокол-М1». Его задача — получить новые наблюдения с исходным временем и идентификатором станции, передать их в общий импорт и после проверки обновить нужную серию InfluxDB. Для просмотра почти в реальном времени добавь отдельную серию срочных наблюдений. Для отчётов сохраняется суточная серия с проверкой полноты. Перед подключением проверь, какой интерфейс включён для Кр1 и Кр2 и с каким шагом доступны измерения.
