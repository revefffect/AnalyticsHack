# Метеоагент и данные

В видео около **05:10** виден каталог Yandex AI Studio с DeepSeek V4.1 Flash 1017, Qwen3.6-35B, Alice AI LLM Flash и YandexGPT 5.1 Pro. Около **06:05** докладчик создаёт текстового агента с DeepSeek и показывает подключение поискового индекса. Для портала выбран актуальный API-идентификатор `deepseek-v4.1-flash`. Модель можно заменить одной настройкой. [Модели Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models)

## Сценарий внутри Метеоархива

1. Откройте станцию и загрузите через каталог CSV, XLSX, JSON или ZIP. Подтвердите, какая колонка содержит время и какие колонки содержат показатели.
2. В отчёте по версии выберите показатель, даты и шаг, затем нажмите **«Открыть в Метеоагенте»**.
3. Посмотрите покрытие и причины исключения. Для облачного режима можно раскрыть **«Посмотреть данные для модели»**, задать вопрос и подтвердить отправку. Например, «Почему по Кр1 нет среднемесячного давления за апрель 2024? Как это написать в отчёте?».
4. Сверьте черновик с отчётом и исходными строками по ссылке на странице. Без настройки облака экран уже показывает проверяемые результаты и даёт скачать агрегаты.

Портал рассчитывает числа на своём сервере по тому же коду, который строит основной отчёт. Модель получает вопрос, покрытие, сводные причины исключений, пороги кейса и результаты максимум 12 последних периодов. В запросе отсутствуют исходный файл, построчные измерения, имя сотрудника, имя файла и идентификатор версии. Разрешение на просмотр версии проверяется до чтения среза. Ключ хранится на сервере, ответ модели выводится как обычный текст, приложение добавляет собственную ссылку на отчёт. В вызове отправляются `store: false` и `x-data-logging-enabled: false`. [Responses API](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/create-prompt) · [Настройка логирования](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/disable-logging)

## Подключение модели

1. В Yandex AI Studio откройте свой проектный каталог. Для базового запроса документация указывает сервисный аккаунт с ролью `ai.languageModels.user` и ключ с областью `yc.ai.foundationModels.execute`. Идентификатор каталога и секретную часть ключа внесите в окружение приложения. [Создание первого запроса](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/create-prompt) · [Аутентификация](https://aistudio.yandex.ru/ru/docs/ai-studio/api-ref/authentication)
2. Для Compose заполните переменные в `deploy/catalog/.env`. Локально используйте переменные окружения процесса Django.

   ```dotenv
   METEO_AI_FOLDER_ID=
   METEO_AI_API_KEY=
   METEO_AI_MODEL=deepseek-v4.1-flash
   ```

3. Перезапустите приложение, откройте Метеоагента и сделайте пробный запрос по разрешённому срезу. Этот вариант обращается к API с тарификацией по потреблению. Доступность модели, квота и источник оплаты зависят от облачного каталога. [Аутентификация и тарификация эндпоинтов](https://aistudio.yandex.ru/ru/docs/ai-studio/api-ref/authentication)

Значения `qwen3.6-35b-a3b`, `aliceai-llm-flash` и `yandexgpt-5.1` можно настроить для повторного прогона того же вопроса. Для выбора модели сравните точность покрытия и единиц, осторожность вывода при пропусках, время ответа и расход токенов. [Каталог и идентификаторы моделей](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models)

## Самостоятельная проба в облачной консоли

Чтобы повторить сценарий из видео, загрузите разрешённый PDF с методикой или небольшой демонстрационный CSV в **Agent Core → Поисковые индексы**, затем создайте агента в **Agent Atelier → Текстовые агенты**. Выберите DeepSeek V4.1 Flash, подключите индекс и добавьте инструкцию «Отвечай по загруженным материалам, указывай источник. Если данных для ответа недостаточно, скажи, чего не хватает». Этот способ подходит для ответов по методике, инструкциям и обзора файлов. Официальные числа для сводки в портале берутся из расчётного ядра. [Агент с поиском по файлам](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/agents/create-filesearch-text-agent)

Следующие возможные функции — сравнение двух разрешённых версий через серверный расчёт, поиск по PDF правил, черновик печатной сводки и прогноз от отдельного метеопровайдера с датой выпуска и горизонтом.
